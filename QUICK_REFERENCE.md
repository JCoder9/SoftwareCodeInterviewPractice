## 📊 Pattern Frequency in Real Interviews

### Most Common (Seen in 70-90% of interviews)
- Two Pointers
- Sliding Window
- Hash Maps/Sets
- Prefix Sums (Range Query, Subarray Sum K)
- BFS/DFS on Trees
- Graph Traversal
- 1D DP basics

### Very Common (50-70% of interviews)
- Knapsack DP variants
- String DP (LCS, Edit Distance)
- Heaps & Priority Queues
- Binary Search
- Monotonic Stack (Next Greater Element)
- Topological Sort
- Product Array / 2D Prefix Sums

### Common in Top Companies (30-50% of interviews)
- Monotonic Stack
- Binary Search on Answer
- Interval DP
- Advanced Graph (Bidirectional BFS, 0-1 BFS)

### Advanced/Rare (10-20% of interviews)
- Regex/Wildcard Matching
- Remove Boxes / Complex 3D DP
- Alien Dictionary
- All Topological Orderings
- Advanced Backtracking

## 🎓 Study Schedule Examples

### 🟢 Junior Level (8 weeks)
- **Week 1**: Two Pointers Same Direction
- **Week 2**: Two Pointers Opposite Ends + Hash Sets
- **Week 3**: Sliding Window Fixed + Variable
- **Week 4**: Fast/Slow Pointers + Reverse List
- **Week 5**: Basic Tree DFS + BFS
- **Week 6**: Simple DP (Climbing Stairs, House Robber, Kadane's)
- **Week 7**: Prefix Sums (Range Query) + Binary Search
- **Week 8**: Mock Interviews + Review

### 🟡 Mid-Level (12 weeks)
- **Week 1-2**: Advanced Sliding Window + Subarray Sum K + 2D Prefix Sums + Product Array
- **Week 3-4**: Monotonic Stack (Next Greater) + Graph DFS/BFS
- **Week 5-6**: Knapsack DP (0/1, Subset Sum, Coin Change)
- **Week 7-8**: String DP (LCS, Edit Distance) + More 1D DP (Decode Ways, LIS)
- **Week 9**: Heaps + K-way Merge + Binary Search
- **Week 10**: Topological Sort + Sort+Two Pointers
- **Week 11**: XOR Patterns + Backtracking + Full-length practice
- **Week 12**: Mock interviews + weak areas

### 🔴 Senior/FAANG (16 weeks)
- **Week 1-3**: Monotonic Stack/Deque (all patterns)
- **Week 4-5**: Binary Search on Answer
- **Week 6-8**: Interval DP + Advanced String DP
- **Week 9-10**: Advanced Graph (Bidirectional, 0-1 BFS)
- **Week 11-12**: Backtracking + Memoization
- **Week 13-14**: Company-specific hard problems
- **Week 15**: Speed optimization + edge cases
- **Week 16**: Final mock interviews

## 💡 Quick Tips

### For Junior Level
✅ Master the basics before moving on  
✅ Do 5+ problems per pattern  
✅ Explain your approach out loud  
✅ Don't worry about optimization yet  

### For Mid-Level
✅ Time yourself (35-45 min per problem)  
✅ Practice coding without IDE help  
✅ Learn space/time complexity analysis  
✅ Study optimal solutions after solving  

### For Senior/FAANG
✅ Solve problems in multiple ways  
✅ Optimize for edge cases from the start  
✅ Practice system design alongside coding  
✅ Mock interview with peers weekly
